**Como acessar:**

- **Baixar o aplicativo (APK)** — ao clicar, o download do arquivo `doanetv1-release.apk` inicia automaticamente no seu dispositivo. Transfira-o para um celular Android (ou baixe direto por ele), abra o arquivo e confirme a instalação — o Android pode pedir permissão para instalar apps de fontes desconhecidas. Após instalar, o aplicativo **DoaNet** aparece na lista de apps.
- **Painel Administrativo** — ao clicar, o painel Streamlit abre em uma **nova aba** do navegador, já conectado ao back-end na nuvem. Faça login com as credenciais de administrador da organização para gerenciar feed, voluntariado, financeiro e customização.
- **Documentação da API** — ao clicar, o **Swagger UI** do back-end FastAPI abre em uma **nova aba**, listando todas as rotas da API (feed, oportunidades, doações, transparência, organização e administradores). É possível explorar os contratos de cada endpoint e testá-los diretamente pela interface — rotas protegidas exigem token JWT (obtido via rota de login) informado no botão *Authorize*.

!!! note "Primeira utilização"
    Os serviços estão hospedados no plano gratuito do Render e hibernam após um período de inatividade — o **primeiro acesso pode levar até 1 minuto** para responder. Os acessos seguintes são imediatos.
